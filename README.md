# TuxunGram

免费、开源的 Telegram 第三方 Android 客户端，基于 Telegram 官方的 [TDLib](https://github.com/tdlib/td) 库构建。

## 它是什么

- 一个干净、专注的 Telegram 客户端：登录你自己的 Telegram 账号，聊天数据始终在 Telegram 的服务器上，本 App 不经过、也不保存到任何第三方服务器。
- 完全免费，没有广告，没有内购，没有账号系统（除了你自己的 Telegram 账号）。
- 全程开源（GPLv3）：处理登录凭证和聊天内容的软件，代码就应该摆出来给大家看。

## 当前状态

开发中，当前版本 0.9.0。这一版不加新功能面，主题是打磨：全量代码审计修隐藏问题、启动和滚动性能、安装包瘦身和稳定性场景复查——把前面八个版本攒下的底子夯实。

### 聊天

- 手机号登录（含两步验证），登录状态和官方端实时同步
- 对话列表：全部对话自动加载完整，真实头像、未读角标（上限可在设置里选 99+ / 999+ / 9999+）、置顶与静音状态一目了然
- 新设备登录时全量同步：所有私聊、群组、频道都会自动出现在首页，同步期间有明确提示；归档对话有专门的入口查看，联系人也会一并同步
- 长按对话可以置顶、静音、标为已读、归档
- 聊天文件夹不只是能看：首页上方就是文件夹标签，长按任意文件夹可以改名、增删里面的对话、删除文件夹，也可以点「＋ 新建」建一个新的
- 首页顶部有动态（stories）一排头像圈：有新动态的对话圈是彩色的，看过的变灰；点开全屏看图片和视频动态，点左右切换，看完自动标已读
- 聊天记录可以一直翻到这个对话的第一条消息——这次专门修了一个老毛病：以前翻着翻着会误判「已经到底了」，一段老消息就凭空消失，现在改成只有真的没有更早的消息才停；消息列表还加上了日期分隔（今天 / 昨天 / 日期）
- 点聊天顶部可以进资料页：用户简介、共同群组，群组和频道的成员数与成员列表都看得到
- 顶部搜索框一次搜完：对话标题、联系人、所有对话里的消息都能找到，点消息结果直接跳到那条消息的位置

### 消息体验

- 滑动回复：把任意一条消息往左滑，过线就自动引用它回复，带震动反馈，和成熟客户端一个手感
- 双击回应：双击一条消息直接给它加上回应（优先 ❤️，这个对话不允许时自动用它允许的第一个），再双击一次取消
- 多选批量操作：长按消息选「多选」，再点选更多消息，顶栏显示已选数量，底部可以一次转发、一次复制（按时间顺序拼好）、一次删除；返回键先退出多选
- 全屏看图：点图片进全屏查看器，左右滑切换这个对话的前后图片，双指缩放、双击放大，上下滑关闭；顶部有发送者和时间，图片说明在底部
- 视频点开会交给系统播放器播放，不用在 App 里将就
- 草稿跨设备同步：输入框里没发出去的字会自动存成草稿（Telegram 云端同步，你在别的设备上打开同一个对话就能接着写），重新进来自动恢复；发送后草稿自动清除
- 对方状态实时显示：对方正在输入、正在录音、正在发送图片时，聊天顶栏标题下会显示出来；你打字时对方那边也能看到

### 发消息

- 文字、图片、文件、视频、语音消息都能发；点麦克风还能直接录语音，录的时候能看时长、能取消
- 输入栏左边有贴纸/表情入口，点开是停靠在键盘区的三页签面板：表情点一下插入文字；贴纸按「最近用过的在最前」排列，还能按贴纸包一个个浏览，点一下就发；GIF 页签里是保存的动图——不再是一个光秃秃的文字框
- 长按任意消息：回复、复制、编辑（自己的文字消息）、删除、转发、添加表情回应；每个对话只显示它允许的回应，频道里也不会再报错
- 投票消息完整显示题目、选项和票数，点选项就能投票，多选、改票、收票状态都和官方端一致
- 带链接的消息会自动显示网页预览卡片
- 收到的文件、视频、语音点一下就能下载，用你习惯的应用打开播放
- 别人给消息加的表情回应会实时显示计数，你也可以点一下跟一个
- 对话列表右上角可以直接新建群组（从联系人里选成员）和频道，建完自动进聊天

### 加密与安全

- 秘密聊天（端到端加密）：在联系人资料页点「发起秘密聊天」就能建，对方发的秘密聊天也会自动出现在对话列表里，带锁标记和普通聊天分开；文字、图片、文件、语音照常收发
- 秘密聊天的资料页能看到加密状态和密钥指纹，可以和对方核对，确认没有中间人；还能设置阅后即焚（5 秒到 1 周几档可选），看完自动销毁
- 说句实话：秘密聊天的消息只存在于你们两台设备上，不同步云端、不会出现在其他设备上，换手机也找不回来——这是秘密聊天协议本身的设计，所有客户端都一样
- 应用锁：4-6 位数字密码（只存哈希，不存明文），支持指纹解锁；自动锁定时间可选立即 / 1 分钟 / 5 分钟 / 从不，冷启动和超时切回来都要先解锁；密码连错 5 次后要等 30 秒才能再试，之后每多错一次等待翻倍（最长 5 分钟），防止有人拿着你的手机慢慢猜
- 本 App 的数据不进系统云备份：聊天数据库和代理密码这类敏感内容只留在手机上，不会被备份功能拷走
- 会话管理：设置里能看到所有登录着你账号的设备（设备名、地区、IP、登录和最后活跃时间），当前设备有标记；不认识的设备可以逐个结束会话，也能一键退出全部其他设备

### 群组与频道管理

- 你是群主或管理员时，资料页会出现「管理」区：改群名、改简介；点成员可以禁言、解除禁言、封禁、解封；别人的消息也能直接删（对所有人删除）
- 没有相应权限时这些入口根本不显示，不会点了才报错

### 通知与后台

- 内置前台服务保活：App 切到后台甚至划掉后，连接还保持着，新消息会弹系统通知，点通知直接进对应对话；静音的对话和自己发的消息不会打扰你
- 通知按对话分组：多个对话来消息时收成一组，不刷屏；每条通知里可以直接回复（不用打开 App），也能一键标记已读；回复没发出去时通知会如实告诉你，不装作发成功了
- 实话实说：有些手机系统（比如 Flyme）还会拦自启动和后台电量，设置页里写了去哪里放行——那一步只能你自己在系统设置里点，任何 App 都替不了

### 多账号

- 可以登录多个 Telegram 账号，每个账号的聊天数据各自独立存放，互不干扰
- 设置里点一下就能切换账号（App 会自动重启一下回到那个账号），也能再添加新账号；最早登录的账号数据不受影响

### 外观与存储

- 主题三档：跟随系统 / 浅色 / 深色；主题色四套：电报蓝、绿、紫、橙，换完立刻生效
- 聊天背景六套纯色（默认 / 薄雾蓝 / 米纸 / 浅绿 / 粉樱 / 石墨，浅色和深色模式各配了一套）；气泡样式两套（现代圆润 / 经典方正）；字体大小四档（小 / 标准 / 大 / 特大），消息和列表文字一起缩放，全部在设置里选完立刻生效
- 全屏边到边显示：每个页面都留好了状态栏和手势条的安全距离，聊天页的输入栏在键盘弹起时会跟着顶起来，不会被挡住；长列表和长页面都有滚动条，滑到哪一目了然
- 全新的纸飞机图标：自适应图标（前景/背景分离）+ 单色图标，深色主题图标也能正确显示
- 设置里有存储空间一区：TDLib 数据库和下载文件各占多少写得清清楚楚；已下载文件可以逐个打开或删除；「清理文件缓存」只清下载的文件，绝不动数据库和聊天记录（看的时候会自动重新下载），清之前会再问你一次

### 网络

- 内置代理列表（SOCKS5 / MTProto）：可以存多个代理，点哪个用哪个，每个都能单独测速看延迟；启用中的下次打开自动连上，不用再依赖全局 VPN 才能用 Telegram

### 频道评论与话题群组

- 频道帖子如果关联了讨论组，长按帖子会出现「评论」入口：点开就是这条帖子的评论区，能看、能发、能回复、能加回应，和在官方客户端里一样
- 开启了话题的群组，打开后先看到话题列表（图标、未读数、最后一条消息一目了然），点进话题就是那个话题自己的消息流，发言只发到这个话题里；普通群组不受影响

### 贴纸包管理

- 设置里有「贴纸包管理」：已装的贴纸包带着封面和张数列出来，不用的可以移除；把 t.me/addstickers 链接或包名粘进去就能添加新包，聊天里的贴纸面板会立刻跟着更新

### 机器人按钮

- 机器人消息下面的内联按钮可以点了：链接按钮打开浏览器，回调按钮会把结果按机器人返回的样子展示（弹提示、弹对话框或打开链接），需要两步验证密码的按钮会先让你输密码；复制类按钮点一下就复制好

### 发动态

- 首页动态排最前面有「发动态」入口：选一张照片、确认就发布，隐私默认所有人可见（确认框里写明），24 小时后自动归档；账号暂时没有发动态资格时（比如需要 Premium），会直接告诉你原因，不会假装发成功

### 打磨（0.9.0）

- 安装包瘦身：从 41 MB 压到 14.5 MB——代码和资源经过压缩，原生库在包内压缩存放；功能一个不少，老版本直接覆盖安装
- 启动更快：核心库改到后台加载，界面先出来，不再点开图标先卡一下
- 滚动更顺：看过的头像、图片、贴纸会缓存在内存里（上限 24 MB，自动淘汰最久没用的），列表来回滑动不用每次重新读盘解码
- 全量审计修复：大图预览和动态查看改为按需缩放解码，不再有内存溢出的风险；录音途中退出聊天页会立刻停掉麦克风；引用回复的摘要不会再串到别的对话；文件夹操作失败时显示人话提示，不再甩服务器原文；贴纸和 GIF 面板每次打开都会刷新，不会漏掉新装的包
- 稳定性复查：断网启动、无网发送、飞行模式恢复、代理失效、存储快满时发图、进程被系统回收后从通知点进——六个场景逐条对着代码检查过，发送失败一定会如实显示，不会假装成功

### 还没做的

语音/视频通话不在计划内。

## 技术

- Kotlin + Jetpack Compose
- TDLib（官方 C++ 库）在 CI 中从源码编译为 arm64 的 `libtdjson.so`，App 通过其 JSON 接口与之通信
- 只做 Android（minSdk 29），arm64

## 构建

正式签名与 Telegram api 凭证都通过 GitHub Secrets 在 CI 注入，不写进仓库。
