# TuxunGram 1.0.0

TuxunGram 的第一个正式版本：一款免费、开源的 Telegram 第三方 Android 客户端，基于 Telegram 官方的 TDLib 库构建。没有广告，没有内购，没有自己的服务器——登录的是你自己的 Telegram 账号，聊天数据始终在 Telegram 那边。

## 新功能

### 聊天与同步
- 手机号登录（含两步验证密码），登录状态与你的其他设备实时同步
- 新设备登录全量同步：所有私聊、群组、频道自动出现在首页，联系人一并同步，同步期间有明确提示
- 聊天记录可以一直翻到第一条消息；对话多得再多，列表也会自动加载完整
- 聊天文件夹：首页上方切换，长按可以改名、增删对话、新建和删除文件夹
- 归档对话有专门入口；收藏夹（给自己发消息）固定在列表顶部
- 全局搜索一次搜完对话标题、联系人和所有消息，点结果直接跳到那条消息
- 对话列表会优先显示没发完的草稿（红色「草稿：」前缀）；聊天页可以按日期跳到某一天的消息
- 动态表情消息按大号贴纸显示，点一下播放声音和特效
- 每个对话可以单独设消息自动删除（1 天 / 1 周 / 1 个月），也可以给单个对话设专属壁纸

### 发消息
- 文字、图片、视频、文件、语音消息、贴纸、GIF、投票（包括测验模式）都能发
- 照片和视频可以多选打包成相册发送，收到的相册成组显示
- 位置和联系人名片可以分享，收到的位置点开就跳地图
- 长按发送键可以静默发送，或定时发送（1 小时后、今晚、明早、对方上线时、自定义时间）
- 输入一半退出，草稿还在，还会同步到你的其他设备
- 回复、编辑、删除、转发、多选批量操作都在长按菜单里；消息可以置顶，聊天顶部有置顶栏
- 引用回复可以只引用对方消息中的一段文字；公开对话里的消息可以长按复制公开链接
- 发消息支持轻量格式标记（粗体、斜体、代码、剧透、文字链接），写好发出去就是带格式的
- 群聊里输入 @ 有成员建议、输入 # 有用过的标签建议；在任何聊天输入 @机器人 可以直接用内联机器人（出结果面板，点一条就发）

### 看消息
- 富文本完整渲染：粗体、斜体、代码、链接、@提及、剧透遮罩（点了才显示）
- 会员自定义表情在文字里直接显示成小图
- 图片全屏查看器（左右翻、双指缩放），视频在应用内播放，语音带波形进度条和倍速
- 圆形视频消息能看能发（附件里录一段直接发）；骰子消息显示点数，游戏消息能点「开始游戏」
- 长按消息可以翻译（由 Telegram 服务器提供，需要 Premium 的账号被拒绝时会如实提示）
- 自己发的消息可以看「谁看过」（太早或被隐私挡住时会如实说明）
- 频道评论区、话题群组都能进、能发；机器人消息下面的按钮可以点
- 资料页有共享媒体：图片、视频、文件、链接分开看
- 任意对话的聊天记录可以导出成 .txt 文件（最近 1000 条或全部，带进度、可取消）；在聊天里下载过的文件有集中的下载管理页

### 动态与贴纸
- 首页顶部一排动态头像圈，点开全屏看；也能发自己的图片动态
- 输入框左侧打开表情 / 贴纸 / GIF 三页签面板，贴纸最近用的排最前，点一下就发
- 贴纸包可以搜索、看热门、整包添加，也能在设置里管理已装的包

### 隐私与安全
- 秘密聊天：端到端加密，可设阅后即焚，资料页能看密钥指纹
- 应用锁：PIN 或指纹解锁，连错 PIN 会自动锁定一段时间
- 已登录设备一目了然：能逐个退出，也能一键退出其他全部设备
- 隐私设置齐全：上次在线、手机号等 14 项都能设为所有人 / 联系人 / 没人
- 两步验证在应用内管理：开 / 改 / 关密码、管理恢复邮箱，不用去别的客户端
- 通知偏好（私聊 / 群组 / 频道的静音、预览、提醒）存在服务器上，与官方客户端互通
- 黑名单：资料页拉黑，设置里集中管理
- 同步手机通讯录是手动的：通讯录页点一下、先讲清再经你许可才读，只在手点时触发

### 账号与网络
- 多账号同时在线：登录的每个账号都保持连接，后台账号来消息照样弹通知（带账号名），点通知自动切到那个账号打开对话，快捷回复也由消息所属账号发出，不串号；账号列表里每个账号带自己的未读数
- 内置代理列表：SOCKS5 / MTProto 可存多个、点一下切换、每条能测延迟；代理密码加密保存在本机；可开启代理自动故障切换（当前代理连不上时按顺序试下一个）
- 媒体自动下载可按移动网络 / 漫游 / WiFi 分别设档位，设置存在服务器上、与官方客户端互通
- 流量统计：设置里能看发出 / 收到各用了多少流量（按内容和连接类型分开计，本机计数、不上传）
- 后台通知：应用被划掉也能收消息通知，通知里可以直接回复或标已读
- 能改自己的名字、简介、头像和用户名；资料页能看自己和他人的历史头像（自己的旧头像可删）

### 管理工具（你管的群和频道）
- 改名、改简介、换群头像、删任意成员的消息
- 成员列表页：搜索成员，禁言、封禁、升降管理员
- 邀请链接：新建带名字的链接、看通过人数、随时撤销
- 群权限开关、慢速模式、内容保护（防转发）都能在应用里设
- 管理员日志：改名 / 禁言 / 踢人 / 改权限 / 删消息等管理动作按时间可查，可按大类筛选
- 入群申请审批：带待处理数，可逐个或一键批准 / 拒绝
- 群 / 频道统计：成员数、消息数、浏览量与最活跃发言者（服务器允许时显示，不给会说明原因）
- 反垃圾与隐藏成员名单两个服务器开关，有权限的管理员可见可改
- 话题管理：论坛群话题可新建、改名、关闭 / 重开、删除

### 外观
- 界面整体采用官方默认样式：官方浅色 / 深色配色、官方式气泡与对话列表、单行顶栏与左侧抽屉菜单、全屏搜索页、设置单列排版、官方形态的登录流程（国家选择器、验证码格子）
- 主题预设可选「官方主题」，或继续用自定义强调色（蓝、绿、紫、橙四套）；深色 / 浅色 / 跟随系统三档
- 聊天背景：官方风格涂鸦背景、6 套纯色、你自己的照片，还能给单个对话设专属壁纸
- 气泡圆角两档；字体大小四档；全 App 过渡动画跟随系统的动画时长设置
- 底部导航栏保留（对话 / 联系人 / 设置 / 我的），也可以在设置 → 外观里关掉、只用抽屉导航
- 桌面图标是全套自适应图标，跟随系统主题图标变色

## 优化

- 安装包从早期版本的 41 MB 瘦到约 15 MB，功能一个没少
- 冷启动不再卡在加载上；图片有缓存，列表滚回来不重新解码
- 设置可以导出成文件备份（代理密码不进文件），重装或换手机能导回来
- 设置里手点「检查更新」就能看有没有新版本
- 两处纯客户端的展示截断被放宽（客户端展示放宽，服务器规则不变）：单个对话的置顶消息可以翻页看完，不再截断在 100 条；贴纸搜索一次返回 100 个结果

## 修复

- 修好了老消息「有时看得到、有时看不到」：以前翻历史翻到一半会被误判到底，一段消息就此消失；现在只有真的没有更早的消息才停
- 频道里给消息加回应不再报 400：回应选择器只显示这个频道允许的回应
- 切账号后，上一个账号的通知会清干净，不会串号
- 从相册选图回来不会被应用锁误锁；编辑文件夹时成员没加载完不能误保存
- 大图预览不再有内存爆掉的风险；录音中途退出聊天会停掉麦克风
- 应用锁 PIN 连错会锁定；应用数据不再允许被云备份拷走

## 已知说明

- 语音和视频通话暂未提供
- 本应用使用自有的 Telegram api 凭据构建；签名密钥与 api 凭据只通过 GitHub Secrets 在打包时注入，仓库里不存任何一份
- 秘密聊天的消息只存在于参与的两台设备上，换设备找不回来——这是秘密聊天协议本身的设计
- 部分厂商的系统（例如 Flyme）还需要在系统设置里给 TuxunGram 放行自启动和电池无限制，后台通知才稳，应用内设置页有指引
